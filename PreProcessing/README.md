# Preprocessing
1. Put all the raw dataset inside the `Uncleaned_data`. The exact file types should be `zip` for NVD, `csv` for ICSA and MITRE ATT&CK and `xml` for the rest. 
2. Run the all the code inside `Code`.

Note: The output can either be in ready-to-use node/relationship form, or a cleaned dataset that still needs splitting into nodes and relationships.
